# Background music

Put royalty-free tracks (`.mp3`, `.wav`, `.m4a`, `.ogg`) here to use them for every niche,
or in `niches/<niche>/music/` for one niche only. A different track is picked for each video.

Free sources: the YouTube Audio Library (studio.youtube.com, filter "Attribution not required") and pixabay.com/music.
Without any tracks, ShortForge uses a generated beat.

Tracks in this folder are not committed to git, so their licences stay your responsibility.
